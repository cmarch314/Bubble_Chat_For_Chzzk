# 몬스터 구현 표준

이 문서는 디아블로스 리뷰에서 확정한 지상 이동 규칙과 레우스 리뷰에서 확정한 비행 규칙을 합친 구현 기준이다. 새 몬스터는 예외 코드를 추가하는 대신 아래 계약을 데이터로 조립한다.

## 1. 자료와 출시 조건

1. 최신 등장작을 우선하되, 원종의 정체성이 흐려졌다면 인터뷰에서 지정한 작품을 기준으로 한다.
2. 일본 위키·공략·TA 자료를 우선 조사하고 영어·한국어 자료로 교차 검증한다.
3. 발견하지 못한 행동은 추측해 채우지 않고 `unresolved`로 보고한다.
4. 기술명, 조건, 연계, 대상 수, 부위 파괴 변화, 전달 방식, 음향 근거를 함께 기록한다.
5. 검토가 끝난 ID만 `HuntMonsterReleasePolicy`에 공개한다.

## 2. 모든 몬스터의 행동 계약

모든 공격은 다음 다섯 단계를 갖는다.

`telegraph → travel → impact → return → recovery`

- `telegraph`: 자세와 전조만 표시한다. 피격·회피·가드 판정을 내리지 않는다.
- `travel`: 돌진, 잠복, 도약, 횡단처럼 실제 위치가 바뀌는 구간이다.
- `impact`: 실제 접촉 시점에 대상을 다시 검사한 뒤 피격·회피·가드를 독립 판정한다.
- `return`: 돌진·급습·횡단을 마친 몬스터를 자연스럽게 전장 기준 위치로 돌려놓는다.
- `recovery`: 공격 위력에 맞는 ATB 비용을 회복하며 빈틈 자세를 유지한다.

이동 중 대경직·기절·마비·수면·함정이 발생하면 남은 궤적과 예약 충돌을 즉시 폐기하고 기준 위치에서 해당 상태 자세를 취한다. 대상이 수레·귀환·무적 이탈로 유효하지 않게 되면 재지정 가능 여부를 패턴 데이터로 판단하고, 불가능하면 빗나감 반응으로 끝낸다.

연속 행동은 복제된 독립 공격이 아니라 한 행동 안의 `impactTimeline`으로 작성한다. 각 타격은 개별 대상 유효성 및 방어 판정을 거치며, 반복 횟수·대상 고정·부위 파괴 후 약화도 데이터에 둔다.

## 3. 부위와 대경직

- 체력 80/60/40/20% 같은 공통 구간은 대경직을 만들지 않는다.
- 부위 파괴, 타격 기절, 상태이상, 함정, 섬광, 패턴 고유 실패만 대경직 원인이 된다.
- 지상 부위 파괴는 기본적으로 짧은 경직이다. 다리·핵심 부위의 넘어짐은 조사 근거가 있을 때만 프로필에 둔다.
- 공중에서 실제 부위가 파괴되거나 대경직·기절·마비·수면이 발생하면 즉시 강제 착지하며 일반 대경직의 1.5배 동안 쓰러진다.
- UI에는 파괴 가능한 부위만 `머리 → 등/몸통 → 다리 → 날개 → 꼬리` 순으로 희미하게 표시한다. 파괴 시 굵은 사선을 긋되 내구 수치는 공개하지 않는다.
- 뿔이 머리 파괴로 취급되는 몬스터는 내부 좌우 부위를 유지하면서 머리 아이콘을 파괴 횟수만큼 표시한다.

## 4. 비룡 골격

기본 비행 계약은 다음과 같다.

- 비행 60초, 공중 회피 50%.
- 지상과 공중 패턴 풀을 분리한다.
- 이륙·착륙·저공 횡단·급강하는 모두 위의 다섯 행동 단계를 사용한다.
- 비행 종료 행동은 몬스터별 프로필이 정한다. 레우스 원종은 탈진 중이 아니면 밟기 공격으로 착지한다.
- 재비행 후보 쿨다운은 30초이며 파괴된 날개 하나당 15초 증가하여 최대 60초다. 쿨다운 종료는 강제 이륙이 아니라 이륙 행동의 재선택 허용이다.
- 비행 중 설치한 지상 함정은 남아 있다가 착지 공격이 끝난 뒤 발동한다.
- 누적 공중 피해 게이지는 사용하지 않는다. 관찰 가능한 실제 사건만 격추를 만든다.

## 5. 전달 방식과 애니메이션

- 브레스는 `projectile`, `laser`, `cone`, `gas`, `ground-dot`를 구분한다. 근거 없이 레이저로 대체하지 않는다.
- 투사체는 입의 현재 위치에서 충돌 시점에 잠긴 목표 위치로 이동한다.
- 육탄 공격은 실제 목표까지 이동한다. 제자리 흔들기만으로 접촉을 대신하지 않는다.
- 화면 밖 횡단은 진입 전조, 전체 이동, 복귀 위치를 별도 단계로 둔다.
- 몬스터 애니메이터는 카드가 아니라 몬스터 이미지의 라이브 경계를 기준으로 한다.

## 6. 구현 순서와 검증

1. 근거 레코드와 미해결 항목 작성
2. 골격 및 부위 프로필 선택
3. 패턴 데이터와 상태 조건 작성
4. 공통 실행기에서 타이밍·대상·중단 검증
5. 부위 파괴와 패턴 변화 연결
6. 음향 근거 연결
7. 50회 시뮬레이션
8. 1920×1080에서 전조·충돌·복귀·UI 확인

최소 테스트는 준비 자세에 조기 판정이 없는지, 이동 중 대상 소실에 멈추지 않는지, 중단 시 원점으로 복귀하는지, 각 타격이 개별 판정되는지, 공중 부위 파괴가 강제 착지가 되는지, 지상 부위 파괴가 허위 대경직을 만들지 않는지를 포함한다.
