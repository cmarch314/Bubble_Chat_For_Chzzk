# 몬스터별 결정 기록

이 폴더는 몬스터 고유의 조사 근거, 인터뷰 결정, 미결사항만 보관한다. 공통 행동 계약은 `../../monster-implementation-standard.md`를 따르며 여기서 반복하지 않는다.

- 파일명은 키트 ID와 같은 `<id>.md`를 사용한다.
- 변종이 원종과 공유하는 결정은 원종 문서를 링크하고 차이만 기록한다.
- 작업할 때 공통 규정과 현재 몬스터 문서 하나만 읽는다.
- 확정 답은 즉시 기록하고, 구현·테스트가 끝나면 해당 체크 항목을 갱신한다.
- 비행 가능한 몬스터는 비행 방식·지속 조건·공중 회피율·재진입 조건을 문서와 프로필에 직접 선언한다. 하나라도 암묵적인 공통값으로 추정하지 않으며 비행 프로필이 없으면 비행 불가다.

## 현재 정리된 원종

- `diablos.md`: 잠복 급습 등 디아블로스 고유 행동
- `rathalos.md`: 백스텝 브레스 이륙과 레우스 비행
- `rathian.md`: S자 활강·서머솔트·삼연속 돌진
- `bazelgeuse.md`: 폭린 생명주기·살포·융단폭격
- `legiana.md`: 냉기 부착 효과·짧고 빠른 비행 연계
- `nargacuga.md`: 비가시적 시간 순환 후보와 이후 인터뷰
- `nergigante.md`: 비가시적 시간 순환 후보와 강화 가시 기믹 분리
- `tigrex.md`: 진행 중인 티가렉스 인터뷰

아종·희소종·특수개체는 원종 문서를 기본으로 참조하되, 원종과 달라진 패턴만 별도 문서를 만든다.
