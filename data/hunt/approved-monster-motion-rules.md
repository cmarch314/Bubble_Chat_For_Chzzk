# 승인된 몬스터 모션 공통 규칙

이 문서는 티가렉스 모션 검수에서 사용자 승인을 받은 항목만 기록한다. 몬스터 고유 패턴은 공통 규칙으로 승격하지 않는다.

## 판정과 행동 소유권

1. 근접 공격은 공격 부위가 목표 충돌 지점에 도달한 프레임에 판정한다. 투사체는 목표 도달 프레임에 판정한다.
2. 여러 이동 구간과 마무리로 이루어진 연속 패턴은 하나의 ATB 행동이다. 전체 종료 전에는 새 행동을 시작하지 않는다.
3. 연속 행동의 ATB 비용은 개별 타격마다 차감하지 않고 전체 연출 시간과 최종 후딜을 합쳐 한 번 산정한다.

## 이동과 복귀

4. 위치 이동 래퍼와 이미지 방향 레이어를 분리한다. 래퍼는 좌표만 이동하고 이미지 레이어만 좌우 반전한다.
5. 다단 돌진은 각 횡단 시작 위치에서 현재 목표까지 직선 충돌 경로를 다시 계산하며 출발부터 일정한 돌진 속도를 유지한다.
6. 화면 안에서 끝난 패턴은 현재 위치에서 기본 위치로 자연스럽게 이동한다. 화면 밖에서 끝난 패턴은 화면 상단에서 내려오며 페이드인한다.

## 중단과 상태 전환

7. 대경직·기절·마비·수면 등 강제 상태 발생 시 이동 궤도, 예약 타격, 예약 음향을 취소하고 즉시 상태 모션으로 전환한다. 중단된 공격은 재개하지 않는다.
8. 공격 도중 분노·탈진·특수강화 종료 조건이 충족되면 현재 행동과 후딜을 마친 뒤 상태를 전환한다. 새 배율·오라·패턴 선택은 다음 행동부터 적용한다.

## 음향과 투사체

9. 이동음·발사음·충돌음·폭발음은 각각 실제 스텝·발사·충돌·폭발 프레임에서만 재생한다.
10. 투사체 시작점은 발사 순간의 실시간 몬스터 이미지 위치, 좌우 반전 상태, 지정 부위 앵커로 계산한다.

## 모션 생명주기와 검수

11. 모든 모션은 실행 세대 번호를 가진다. 현재 세대와 일치하지 않는 타이머와 종료 이벤트는 위치·투명도·상태를 변경할 수 없다.
12. 패턴 검수는 실 수렵과 동일한 1920×1080 레이아웃에서 수행한다. 패턴별 타겟, 충돌 시점, 복귀, 방향, 음향을 독립적으로 재현할 수 있어야 한다.

## 공통 규칙에서 제외한 티가렉스 전용 항목

- 마지막 횡단 뒤 목표 앞까지 별도 접근하고 바위·회전·깨물기 파생을 시작하는 구조
- 비분노/분노 연속돌진 횟수와 파생 가중치
- 돌진 스텝 반전 주기와 전용 스텝 음향
- 벽에 이빨이 박히는 실패 리액션
- 탈진 연속돌진 뒤 넘어짐
- 지역별 바위 속성 변화
