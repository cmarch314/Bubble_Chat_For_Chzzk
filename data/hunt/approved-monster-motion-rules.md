# 승인된 몬스터 모션 공통 규칙

이 문서는 티가렉스 모션 검수에서 사용자 승인을 받은 항목만 기록한다. 몬스터 고유 패턴은 공통 규칙으로 승격하지 않는다.

## 판정과 행동 소유권

1. 근접 공격은 공격 부위가 목표 충돌 지점에 도달한 프레임에 판정한다. 투사체는 목표 도달 프레임에 판정한다.
2. 여러 이동 구간과 마무리로 이루어진 연속 패턴은 하나의 ATB 행동이다. 전체 종료 전에는 새 행동을 시작하지 않는다.
3. 연속 행동의 ATB 비용은 개별 타격마다 차감하지 않고 전체 연출 시간과 최종 후딜을 합쳐 한 번 산정한다.

## 이동과 복귀

4. 위치 이동 래퍼와 이미지 방향 레이어를 분리한다. 래퍼는 좌표만 이동하고 이미지 레이어만 좌우 반전한다.
5. 다단 돌진은 각 횡단 시작 위치에서 현재 목표까지 직선 충돌 경로를 다시 계산한다.
6. **모든 돌진형 공격은 출발 후 0.5초 동안만 가속해 최고 속도에 도달하고, 그 뒤로는 접촉까지 속도가 변하지 않는다.** 느린 상태를 끌다가 뒤늦게 빨라지는 곡선을 쓰지 않는다. 꺾이는 경로(지그재그·교차)에서도 방향만 바뀔 뿐 속도는 유지한다.

   구현 규칙:

   - 이징은 항상 `linear`로 둔다. CSS의 `animation-timing-function`은 애니메이션 전체가 아니라 **키프레임 구간마다** 적용되므로, 클래스에 `cubic-bezier`를 걸면 경유점마다 감속·재가속이 반복된다.
   - 가속은 **출발 프레임 하나에만** `animation-timing-function:cubic-bezier(.333,0,.667,.333)`로 건다. 이 곡선이 등가속 운동의 위치 곡선(위치 ∝ 시간²)이다. 다음 키프레임까지가 가속 구간이 된다.
   - 램프 길이 `r`(%)는 `500ms / 재생시간 × 100`이다. 재생시간은 모션마다 다르므로 값도 모션마다 다르다.
   - 출발 프레임 `L`, 접촉 프레임 `C`일 때 최고 속도와 램프 종료 지점은 다음과 같다. 이렇게 두면 가속 구간과 등속 구간이 이어지는 지점에서 속도가 튀지 않는다.

     ```
     v = 1 / (C - L - r/2)          # 진행도(0~1) / %
     램프 종료:  위치 L + r 에서 진행도 v * r / 2
     이후 각 프레임:  진행도 = (해당 % - L - r/2) * v
     ```

   - 경로가 꺾이는 모션은 진행도를 x좌표가 아니라 **누적 경로 길이**로 잡는다. x만 보면 되돌아오는 구간에서 속도가 음수로 읽힌다.

7. 화면 안에서 끝난 패턴은 현재 위치에서 기본 위치로 자연스럽게 이동한다. 화면 밖에서 끝난 패턴은 화면 상단에서 내려오며 페이드인한다.

## 중단과 상태 전환

8. 대경직·기절·마비·수면 등 강제 상태 발생 시 이동 궤도, 예약 타격, 예약 음향을 취소하고 즉시 상태 모션으로 전환한다. 중단된 공격은 재개하지 않는다.
9. 공격 도중 분노·탈진·특수강화 종료 조건이 충족되면 현재 행동과 후딜을 마친 뒤 상태를 전환한다. 새 배율·오라·패턴 선택은 다음 행동부터 적용한다.

## 음향과 투사체

10. 이동음·발사음·충돌음·폭발음은 각각 실제 스텝·발사·충돌·폭발 프레임에서만 재생한다.
11. 투사체 시작점은 발사 순간의 실시간 몬스터 이미지 위치, 좌우 반전 상태, 지정 부위 앵커로 계산한다.

## 모션 생명주기와 검수

12. 모든 모션은 실행 세대 번호를 가진다. 현재 세대와 일치하지 않는 타이머와 종료 이벤트는 위치·투명도·상태를 변경할 수 없다.
13. 패턴 검수는 실 수렵과 동일한 1920×1080 레이아웃에서 수행한다. 패턴별 타겟, 충돌 시점, 복귀, 방향, 음향을 독립적으로 재현할 수 있어야 한다.

## 공통 규칙에서 제외한 티가렉스 전용 항목

- 마지막 횡단 뒤 목표 앞까지 별도 접근하고 바위·회전·깨물기 파생을 시작하는 구조
- 비분노/분노 연속돌진 횟수와 파생 가중치
- 돌진 스텝 반전 주기와 전용 스텝 음향
- 벽에 이빨이 박히는 실패 리액션
- 탈진 연속돌진 뒤 넘어짐
- 지역별 바위 속성 변화
