# 리오레이아 최종 구현 감사

검수일: 2026-07-28

## 기준

- 작품 기준: `Monster Hunter: World / Iceborne` 원종
- 역할: 짧은 비행 연계와 독 서머솔트가 핵심인 지상형 비룡
- 필살기: 없음. 금화룡·은화룡 구현 때 별도 설계
- 공개 상태: `HuntMonsterReleasePolicy` 검수 목록 포함
- 참고 자료:
  - https://mhworld.kiranico.com/ja/monsters/Rz9Tb/rioreia
  - https://mhworld.jp/m/d/20
  - https://gamewith.jp/mhw/87033

## 지상 패턴

| 패턴 | 평상시 | 분노 | 판정 |
| --- | --- | --- | --- |
| 물어뜯기 | 1회 | 1회 | 단일 대상 |
| 이단 꼬리 회전 | 2회, 1초 간격 | 동일 | 주 대상과 인접 대상 |
| 화염구 | 1발 | 사용 안 함 | 직선 투사체 |
| 삼연 화염구 | 사용 안 함 | 중앙→좌→우, 0.5초 간격 | 화면 밖 방향은 허공에 발사 |
| 돌진 | 1회 | 사용 안 함 | 주 대상과 인접 1명 |
| 삼연속 돌진 | 사용 안 함 | 3회 | 매 회 독립 재조준, 같은 대상 재선택 가능 |

- 분노 화염구 각 발은 분노 보정 포함 일반 화염구의 130% 위력이다.
- 탈진 중 화염구 선택은 연기만 나는 불발 동작으로 대체한다.
- 탈진 돌진 뒤의 비틀거림은 공통 회복 규칙을 따른다.

## 짧은 비행 연계

평상시:

- 서머솔트 → 착지
- 이륙(전체 풍압[소]) → 저공 활공 → 착지

분노:

- 이륙(전체 풍압[소]) → 천천히 접근해 물기 → 같은 대상 서머솔트 → 착지
- 서머솔트 이륙 → 독립 재조준 서머솔트 → 착지
- 서머솔트 이륙 → 독립 재조준 저공 활공 → 착지

세부 계약:

- 지상과 비행 시도 비율은 6:4이며 재사용 대기시간은 없다.
- 서머솔트는 시계 방향 360도 회전, 전체 동작의 약 30% 지점에서 충돌한다.
- 저공 활공은 4초 동안 S자 접근 후 목표만 타격하고 인접 헌터에게 풍압[소]를 준다.
- 비행 중 부위 파괴·기절·마비·수면·섬광은 현재 연계를 취소하고 즉시 강제 착지시킨다.
- 섬광은 네 번째까지 유효하며 강제 착지 대경직은 일반 대경직의 1.5배다.

## 날개 파괴와 탈진

- 날개 정상: 비행 시도 실패 없음.
- 날개 한쪽 파괴: 이륙 순간에만 35% 실패.
- 양쪽 파괴: 이륙 순간에만 70% 실패.
- 실패 시 공격과 풍압 없이 5초 비틀거림.
- 탈진 중 이륙 성공 시 3초 공중 비틀거림 → 착지 → 3초 지상 비틀거림.
- 같은 날개 실패 규칙은 레우스에도 적용하되 성공한 레우스의 장시간 비행은 유지한다.

## 부위 변화

- UI 순서: 머리, 등, 왼쪽 날개, 오른쪽 날개, 꼬리.
- 머리 파괴: 화염구 피해 20% 감소, 명중률 25% 감소.
- 꼬리 절단: 꼬리 회전과 서머솔트 피해 30% 감소.
- 꼬리 절단: 꼬리 회전과 서머솔트의 범위는 단일 대상이 되며 독이 사라진다.
- 등 파괴는 보상과 UI 표시에만 사용한다.

## 오디오

- 포효: 레우스와 공유하는 사용자 확정 World `em001` 포효 경로.
- 서머솔트: 각 회전 충돌마다 사용자 태그 확정 후보 2종을 무작위 재생.
- 물기·비행·날갯짓·대경직·덫·소경직·죽음은 검증된 레우스 계열 풀을 공유한다.
- 의미가 확정되지 않은 VO는 패턴명만으로 임의 배정하지 않는다.
