# 몬스터 패턴 재건 시범 보고서

작성일: 2026-07-25  
상태: 1차 런타임 시범 적용. 패턴·조건·부위 파괴·전달형 자동 검증 완료, 사용자 플레이 검수 대기.

## 범위와 판정 기준

- 시범 대상: 바젤기우스, 오나즈치, 리오레우스, 디아블로스
- 기본 세트: 각 원종이 등장한 최신 본가 액션 작품
- 일본어 공식·데이터베이스·대사전·공략 자료를 먼저 조사했다.
- 한국어·영어 자료는 누락과 상충 여부를 확인하는 보완 자료로만 사용했다.
- 내부 액션명은 화면에서 하나의 완성 행동으로 확인되기 전까지 런타임 기술로 승격하지 않는다.
- 방향, 좌우, 지상·공중 표기만 다른 내부 액션은 플레이어가 같은 기술로 인식하면 하나의 기술과 분기로 합친다.
- 아래의 `확정`은 복수의 독립 자료 또는 데이터와 화면 설명이 일치한다는 뜻이다.
- `잠정`은 행동 자체는 확인됐지만 정확한 연계 조건이나 부위 파괴 후 변화에 영상 검증이 더 필요하다는 뜻이다.
- `보류`는 원시 데이터만 있거나 현재 자료가 충돌해 런타임에 넣지 않는다는 뜻이다.

## 현재 구현에서 즉시 차단할 오류 유형

| 오류 | 현재 사례 | 판정 |
|---|---|---|
| 개발·랭크 표기 노출 | `【MR】 꼬리내려찍기`, `【 】 점프` | 표시 금지 |
| 히트 데이터의 기술 승격 | `ジャンプ用ダメージアタリ` → 점프 | 제거 |

## 1. 바젤기우스

### 기본 작품과 핵심 정체성

- 기본 세트: `Monster Hunter Rise: Sunbreak`
- 원종과 `홍련의 솟구치는 바젤기우스`는 별도 세트로 유지한다.
- 핵심은 화염 레이저가 아니라 폭린의 설치, 시간차 폭발, 분노 시 빠른 기폭, 비행 폭격과 육중한 착지다.
- 전방 화염 공격인 내부·공략상의 `ブレス`는 실제로 존재한다. 다만 폭린과 무관한 범용 레이저처럼 연출하면 안 된다.

### 확인된 상태 그래프

```text
지상 일반
 ├─ 근접 압박: 물기 / 선회 머리치기 / 몸통박치기 / 꼬리 회전
 ├─ 폭린 설치: 머리·꼬리 동작과 돌진에 폭린 투하
 ├─ 화염 방출: 전방 짧은 화염 공격
 └─ 이륙 → 폭격 비행 → 급강하·착지 → 지상 복귀

분노·적열
 ├─ 폭린이 빠르게 기폭
 ├─ 폭린을 동반한 공격의 공간 위험 증가
 └─ 강한 공격 비중 증가

피로
 ├─ 폭린 투하 횟수 감소
 ├─ 화염 방출 불발
 └─ 큰 공격 뒤 회복 시간 증가
```

`공중 급습`을 단독 무작위 기술로 두지 않는다. `이륙 → 폭린 경로 생성 → 접근 방향 고정 → 급강하 착륙`이라는 하나의 연계로 실행한다.

### 부위 파괴와 은폐된 변화

- 머리 파괴: 머리 쪽에서 떨어지는 폭린 수를 감소시킨다.
- 꼬리 파괴·절단: 꼬리 쪽 폭린 수를 감소시키고 꼬리 공격의 실효 범위를 줄인다.
- 변화는 설명 텍스트로 알리지 않는다. 떨어지는 폭린 밀도와 비어 있는 안전 구역이 눈에 보이게 달라져야 한다.
- 등·날개 파괴가 특정 기술을 봉쇄한다는 근거는 아직 부족하므로 보류한다.

### 자동 대응

- 지연 폭린: 폭린 밀도가 낮은 방향으로 이동한다.
- 적열 폭린: 늦은 이동보다 즉시 이탈·가드·긴급회피 확률을 높인다.
- 폭격 비행: 이동 경로를 횡으로 벗어나고, 섬광을 보유·예약한 성향은 비행 중단을 시도할 수 있다.
- 급강하 착륙: 긴급회피 또는 경로 이탈이 정답이며, 폭린 사이에서 무작위 회피하지 않는다.
- 자원 보존 성향은 일반 지상 구간에서 섬광을 낭비하지 않는다.

## 2. 오나즈치

### 기본 작품과 핵심 정체성

- 기본 세트: `Monster Hunter Rise: Sunbreak`
- `괴이 극복 오나즈치`는 독립 세트다.
- 핵심은 투명화, 안개 상태, 독구슬과 독무의 설치·이동, 혀를 이용한 강탈, 느슨해 보이다 갑자기 이어지는 확정 연계다.
- 연속 레이저는 존재하지 않는다. 내부의 `ビーム状`은 히트 판정 형상을 설명하는 개발 용어다.

### 확인된 상태 그래프

```text
평상
 ├─ 느린 접근과 육탄 견제
 ├─ 혀 직선·횡쓸기
 └─ 독구슬·독무 설치

투명화
 ├─ 윤곽·발밑 흙먼지로 위치 추적 가능
 ├─ 일부 공격 뒤 정지해 공격 기회 제공
 └─ 투명 상태 경직 시 큰 대경직

안개 강화
 ├─ 공격 연계 증가
 ├─ 독 공격 패턴 변화
 └─ 안개 살포 → 스텝 → 독구슬 난사의 확정 연계

머리 파괴
 └─ 완전 투명화 불가, 반투명 윤곽 유지
```

### 부위 파괴와 은폐된 변화

- 머리 파괴는 완전 투명화를 막고 반투명 윤곽을 남긴다.
- 꼬리 절단은 꼬리 내려찍기의 실효 범위와 바위 압박을 약화하는 방향이 유력하다. 정확히 바위가 사라지는지, 수가 줄어드는지는 영상 대조 전까지 잠정으로 둔다.
- 투명화 중 경직은 일반 경직이 아니라 큰 대경직 기회로 사용한다.
- 고룡이므로 모든 함정 경로를 차단한다.

### 자동 대응

- 투명화: 무작위 회피 대신 마지막 위치, 윤곽과 흙먼지를 기반으로 표적 위치 오차를 늘린다.
- 독구슬: 착탄점을 피해 이동하고 잔류 독무를 장판으로 기억한다.
- 독무 밀기·당기기: 화면 중앙 고정 효과가 아니라 기존 장판 좌표를 실제로 이동시킨다.
- 원형 독무: 고리 생성 후 오나즈치의 착지 위치를 보고 안쪽 또는 바깥쪽으로 대응한다.
- 해독 자원 부족 상태에서도 독무 밖으로 이동하는 기본 정답은 항상 남긴다.

## 3. 리오레우스

- 수호룡, 아종, 희소종, 흑염왕과 주인은 독립 세트다.
- Wilds 원종은 지상·비행 모드를 빠르게 전환하며, 비행 중 강약 기술을 섞어 빠른 연계를 만든다.
- 화염구, 짧은 연속 브레스, 회전 화염은 투사체와 휩쓰는 화염이다. 화면을 가로지르는 레이저로 만들지 않는다.

### 부위 파괴와 비행 대응

- 꼬리 절단은 2연속 꼬리 회전의 판정 길이를 실제 이미지 길이에 맞춰 줄인다.
- 날개 파괴는 Wilds에서 강력한 슬링어 중열상탄을 떨어뜨리는 것이 확인된다.
- 날개 파괴가 비행 시간이나 비행 성공률을 직접 낮춘다는 근거는 아직 없으므로 적용하지 않는다.
- 비행 중 큰 경직은 즉시 일반 경직으로 끝내지 않는다. 짧은 추격 가능 경직 뒤 추가 부위 피해가 임계치를 넘으면 격추 대경직으로 전환한다.
- 섬광, 마비와 수면은 비행 상태에서 격추 수단으로 사용할 수 있다.

### 자동 대응

- 화염구: 입 방향과 실제 목표 무기 좌표를 기준으로 횡이동한다.
- 3연속 화염구: 첫 회피 뒤 공격으로 전환하지 않고 최대 3발까지 다음 투사체를 확인한다.
- 회전 화염: 현재 거리에 따라 몸 아래 진입 또는 범위 밖 이탈을 선택한다.
- 독발톱: 해독 자원 여부와 관계없이 발톱 궤적 이탈이 기본 정답이다.
- 비행 중 섬광은 공격 전조가 시작됐을 때 가치가 높도록 하고, 착지 직전에는 낭비하지 않는다.

## 4. 디아블로스

- 직선 돌진: 전조에서 목표 축을 확정하고 좌우로 이탈한다. 돌진이 화면 밖까지 통과한 뒤 감속·회전·복귀하는 빈틈을 실제 시간으로 제공한다.
- 지중 급습: 비분노이며 음폭탄이 남아 있을 때 성향별 확률로 사용한다.
- 분노 중 잠복: 음폭탄을 소비하지 않고 이동·가드·긴급회피로 대응한다.
- 덫과 음폭탄은 서로 다른 자원이다. 잠복 대응을 위해 음폭탄을 평상시 낭비하지 않는다.
- 뿔 파괴 후에도 회피 판단은 유지하되, 가드 가능한 성향은 낮아진 가드 부담을 반영한다.

## 런타임 적용 전 남은 검증

1. 각 기술에 실제 플레이 영상 타임스탬프를 최소 2개씩 연결한다.
2. 오나즈치 포효가 실제 전투 제어용 포효인지 `テスト咆哮` 외의 영상·오디오 근거로 확인한다.
3. 오나즈치 꼬리 절단 후 바위 발사 변화의 정확한 범위를 영상으로 확정한다.
4. 바젤기우스 전방 화염 방출의 실제 길이·폭·폭린 기폭 관계를 프레임 단위로 확인한다.
5. 리오레우스 Wilds 원종의 지상·비행 전환 조건과 고속 활공 연계 횟수를 일반 수렵 영상에서 확인한다.
6. 디아블로스 돌진 후 화면 밖 이동·회전·복귀 시간을 BubbleChat 좌우 공간에 맞게 측정한다.
7. 기술마다 발사 지점, 궤적, 활성 시간, 타수, 후딜과 유효 대응을 구조화한 데이터 레코드로 변환한다.
8. 네 마리 각각 독립 테스트와 도달 가능성 시뮬레이션을 만든 뒤 한 마리 단위로 교체한다.

## 제안 적용 순서

1. 전역 안전 장치: 개발 태그, 조룡·테스트·피격 전용 행, 검증 없는 `레이저` 차단
2. 오나즈치: 잘못된 레이저가 가장 눈에 띄므로 첫 교체
3. 디아블로스: 뿔 파괴 전후 수치와 잠복 대응이 명확해 구조 검증에 적합
4. 바젤기우스: 폭린 장판과 비행 연계 구현
5. 리오레우스: Wilds 지상·비행 행동 그래프와 빠른 전환 구현
