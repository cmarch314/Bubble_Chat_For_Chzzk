# 🎮 BubbleChat 치트시트

치지직 채팅과 연동되는 **인터랙티브 방송 오버레이**입니다.  
시청자가 채팅창에 특정 단어나 명령어를 입력하면 **말풍선**, **효과음(SFX)**, **반응형 비디오**, **화면 연출 이펙트**가 실시간으로 작동합니다.

이 프로젝트는 일반 웹페이지가 아니라 **OBS 브라우저 소스 전용 투명 오버레이**를 기준으로 설계됩니다. 채팅은 화면 하단 최상위 레이어에 유지되고, 게임·비주얼 효과는 방송 화면과 채팅을 함께 사용할 수 있도록 배치됩니다.

## 🛠️ 2. 스트리머를 위한 안내 (Streamer Guide)

### 🚀 설정 및 실행
1. `index.html` 파일을 텍스트 에디터로 엽니다.
2. `<div id="id" chzzkHash="...">` 부분에 본인의 **치지직 채널 고유 ID(Hash)**를 입력합니다.
3. OBS의 '브라우저 소스'로 추가하거나 웹브라우저로 직접 엽니다.

### 🎮 관리자 명령어 (채팅창 전용)
- **`!데모 [초]`**: 테스트용 랜덤 채팅 시뮬레이션을 실행합니다.
- **`!데모 끝`**, **`!데모 중단`**: 시뮬레이션을 즉시 중단합니다.
- **`!사운드`**: 전체 효과음 상태를 전환합니다. **`!소리끄기`**, **`!음소거`**, **`!소리켜기`**로 상태를 직접 지정할 수도 있습니다.
- **`!비주얼`**: 전체 화면 이펙트 상태를 전환합니다. **`!이펙트끄기`**, **`!이펙트켜기`**로 직접 지정할 수도 있습니다.
- **`!알람끄기`**, **`!알람켜기`**: 구독·후원 알람 연출만 제어합니다.
- **`!전체끄기`**, **`!전체켜기`**: 사운드·비주얼·알람을 한꺼번에 제어합니다.
- **`!볼륨평준화 [켜기/끄기/도네/채팅]`**: 측정된 파일별 체감 음량 보정을 변경합니다. 출력 보호용 컴프레서는 계속 유지됩니다.
- **`set [sfx/visual/master] [0.0~2.0]`**, **`!set ...`**: 영역별 볼륨을 직접 저장합니다.
- **`!커맨드`**: 현재 반응형 영상·사운드 명령 목록을 화면에 표시합니다. **`!커맨드 중단`** 또는 **`!중단`**으로 닫습니다.

### 🕹️ 채팅 게임 명령어
- **`!게임`**: 플레이 가능한 채팅 게임 도움말을 표시합니다.
- **`!퀴즈 [라운드]`**, **`!퀴즈 AI [라운드]`**: 사운드 퀴즈를 시작합니다. **`!퀴즈 중단`** 또는 **`!중단`**으로 종료합니다.
- **`!경마`**: 채팅 경마를 시작합니다. 배팅과 응원은 화면에 표시된 번호 또는 선수 이름으로 입력하며, **`!경마 중단`** 또는 **`!중단`**으로 종료합니다.
- **`!레이드`**: 협동 보스 레이드를 시작합니다. 진행 중 **`1`/`!공격`**, **`2`/`!마법`**, **`3`/`!힐`**로 참가합니다.

### ⚙️ 상세 설정 (config.js)
`config.js` 파일에서 더 세밀한 조정이 가능합니다.
- **`HIVE_VOLUME_CONFIG`**: 마스터, 비주얼, SFX 각 영역별 볼륨 조절.
- **`VISUAL_CONFIG`**: 각 이펙트의 지속 시간, 캐릭터 크기, 이동 영역 조정.
- **`NORMALIZER_CONFIG`**: SFX·영상/BGM의 측정 음량 보정 활성화 여부.

로컬 미디어를 추가하거나 교체한 뒤 `npm run analyze:audio`를 실행하면 원본 파일은 변경하지 않고 `js/audio-levels.generated.js`의 보정 명세만 갱신됩니다. OBS `file://` 재생 호환성을 위해 영상과 BGM은 네이티브 볼륨으로, 디코딩된 짧은 SFX는 파일별 게인과 공유 컴프레서로 처리됩니다.

몬스터 원본 음성은 `npm run review:monster-audio`로 로컬 검수판을 연 뒤 `http://127.0.0.1:17930`에서 확인합니다. 검수판은 파일을 평평하게 나열하지 않고 Wwise 이벤트의 RANDOM·SEQUENCE·LAYER 묶음을 유지하며, 포효·브레스·물리공격 또는 직접 입력 태그를 묶음 전체에 즉시 저장합니다. 상단의 완료 상태도 로컬에 보존됩니다. 아종·특수개체는 확인된 원종 음성을 상속할 수 있지만 타종의 고유 발성은 대신 사용하지 않습니다. `*_village` 뱅크는 월드의 포획 후 거점용 비전투 음향으로 분류해 수렵 음성에서 제외합니다.

월드 전용곡처럼 설치 게임에서 근거가 확인된 로컬 BGM은 출처 이벤트·게임 싱크·뱅크·WEM을 `data/hunt/`의 명세에 기록하고 재현 가능한 스크립트로 생성합니다. 예를 들어 `npm run build:world-dedicated-bgm`은 바젤기우스 계열의 전용 수렵곡을 만들며, 생성 음원과 게임 추출 원본은 Git에 포함하지 않습니다. 생성 뒤에는 `npm run analyze:audio`로 방송용 음량 프로필을 다시 측정합니다.

### 🐲 수렵 오토배틀러

- **`!수렵 [몬스터]`**, **`!토벌 [몬스터]`**: 퀘스트 보드 → 모집 → 로드아웃 → 단일 수렵 → 결과 순서로 진행합니다. `!수렵 3 레우스`처럼 1~10마리 대연속 수렵도 지정할 수 있습니다.
- **`!몬헌`**: 소형·중형·대형·고룡·초대형 몬스터와 랜덤 이벤트를 잇는 3스테이지 로그라이크 여정을 시작합니다.
- **`!참가`**: 모집·로드아웃·전투 중 AI 헌터 자리에 참가합니다. 네 명이 차지 않으면 길드 NPC가 자동으로 채웁니다.
- **`!준비`**: 현재 무기와 성향을 잠그며, 전원 준비 시 즉시 출발합니다.
- **`!리롤`**, **`!퍽리롤`**: 로드아웃에서 퍽을 최대 두 번 다시 굴립니다.
- **`!잠금 N`**, **`!해제 N`**: 지정한 퍽의 잠금 상태를 관리합니다.
- **`!추천`**, **`!자동추천`**: 무기와 성향 조합을 자동 추천받습니다.
- **`!대검 지원가`**처럼 **`!무기 [성향]`**을 입력하면 로드아웃을 변경합니다. 14종 무기와 공격형·수비형·베테랑·지원형·몬린이·밸런스형 별칭을 지원합니다.
- **`!1`**, **`!2`**, **`!3`**: 여정에서 다음 사냥감 또는 공동 이벤트 선택지에 투표합니다.
- **`!수렵 중단`**, **`!토벌 중단`**, **`!몬헌 중단`**, **`!중단`**: 진행 중인 수렵을 종료합니다.

#### 전투 중 고수준 작전 및 공동 지원

- **`!공격`/`!공세`**, **`!안전`/`!수비`**, **`!지원`/`!응원`**: 팀의 다음 행동 성향에 투표합니다.
- 참가자는 **`!회피`**, **`!가드`**로 다음 방어 대응 확률을 보조할 수 있습니다.
- 누적 지원 게이지를 사용해 **`!회복`**, **`!섬광`**, **`!함정`**, **`!낙석`**을 발동할 수 있습니다.

전투는 채팅으로 개별 공격을 예약하지 않는 자율 ATB 방식입니다. 위 명령은 AI의 고수준 판단과 공동 지원만 보조합니다. 헌터와 몬스터는 행동 비용만큼 게이지를 소비하고 다시 회복하며, 함정·대경직 중에도 몬스터 ATB는 충전되지만 구속이 끝나기 전에는 행동하지 않습니다. 무기 콤보, 예리도, 속성·상태이상, 부위 파괴, 비행·격추, 함정 면역과 몬스터별 패턴 조건은 각각의 전용 런타임에서 처리됩니다.

여정은 `소형 → 이벤트 → 중형 → 이벤트 → 대형`, `중형 → 이벤트 → 대형 → 이벤트 → 고룡`, `대형 → 이벤트 → 고룡 → 이벤트 → 초대형`의 3스테이지로 진행됩니다. 비보스 조우와 공동 이벤트는 2~3개 후보를 최대 60초 동안 투표하며 전원 투표 시 즉시 확정합니다. 동표·무응답은 시드 기반 기본 선택으로 처리해 진행이 멈추지 않습니다. 전투 보상 제니, 캠프 공용 물약·가루·함정·폭탄, 퍽 잠금, 리롤과 무기 강화가 한 여정 동안 이어집니다.

몬스터 구현은 `전조 → 이동 → 충돌 → 복귀 → 후딜`의 공통 행동 계약을 사용합니다. 준비 자세가 아니라 실제 충돌 시점에 피격·가드·회피를 판정하며, 이동 중 대상 소실이나 대경직에도 행동이 멈추지 않게 정리합니다. 웹·게임 데이터와 인터뷰 검수를 통과해 공개 목록에 등록된 몬스터만 일반 수렵 후보로 등장합니다.

방송용 전투 레이어는 **헌터 카드 < 몬스터 < 헌터 무기** 순서를 강제합니다. 몬스터가 돌진·도약·잠복 복귀처럼 카드 영역까지 이동해도 무기 이미지는 항상 가장 위에서 렌더링됩니다.

시청자 로컬 프로필에는 퍽과 잠금 정보만 저장합니다. 게임에서 추출한 음원·이미지와 원본 아카이브는 `local_assets/monster_hunter/`, `game_extracts/` 등 Git 제외 경로에만 보관하며 저장소에 게시하지 않습니다.

개발 검증은 기능별 `test:*` 스크립트와 `npm test`로 회귀를 확인합니다. 수렵 자산은 `npm run audit:hunt`, 몬스터 근거와 허구 패턴은 `npm run audit:hunt-monsters`, UI는 1920×1080 OBS 화면과 하단 15% 채팅 안전영역을 기준으로 검사합니다.
